# First Aid Sources

The public first-aid guidance in the demo is intentionally conservative and is not a diagnosis or substitute for professional care.

Primary references consulted for the implementation:

- American Red Cross — First Aid Steps: https://www.redcross.org/take-a-class/first-aid/performing-first-aid/first-aid-steps
- American Red Cross — Life-threatening external bleeding: https://www.redcross.org/take-a-class/learn-fa-bleeding-life-threatening-external.html
- American Red Cross — Adult/Child choking: https://www.redcross.org/take-a-class/learn-fa-adult-child-choking.html
- NHS — Burns and scalds: https://www.nhs.uk/conditions/burns-and-scalds/
- Government of India ERSS 112: https://112.gov.in/

The UI tells users to call 112 for urgent emergencies and to follow dispatcher instructions.
